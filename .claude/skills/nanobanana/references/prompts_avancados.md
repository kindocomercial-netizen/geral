# Biblioteca de Prompts por Nicho — Nano Banana Pro 2

## Como usar esta biblioteca

Adapte os prompts abaixo ao tema específico do post. Sempre termine com:
`"No text overlays. No watermarks. Ultra-realistic, high quality."`
